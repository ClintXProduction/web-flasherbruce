# 🚀 DUSCU FLASHER
A website to flash *Bruce* firmware directly via browser using Web Serial API technology. No Python installation, no complex command line needed.

🔗 *Access now:* https://ClintXproduction.github.io/web-flasherbruce/

---
### 🌟 Main Features
- *Online Flashing:* Install Bruce firmware with just a few clicks.
- *No Installation:* Only need a browser (Chrome, Edge or Chromium-based browsers).
- *High Speed:* The erase and flash writing process is fast and stable.
- *Friendly Interface:* Easily track progress via live logs.

### 🛠 Supported Devices
This tool supports boards based on ESP32 chips (commonly used for ESP32-S2, etc.):
- ESP32 / ESP32-S2 / ESP32-C3 / ESP32-S3

### 📖 How to Use
1. *Connect Device:* Plug the ESP32 board into the computer via a good quality USB cable.
2. *Open Browser:* Use Google Chrome or Microsoft Edge (latest version).
3. *Select Connect:* Click the "Connect" or "Install" button on the website.
4. *Select COM Port:* A window pops up, select the correct COM port of the device and click "Connect".
5. *Flash Firmware:* Follow the on-screen instructions (usually select the build and press Install).
6. *Complete:* Wait for the progress bar to reach 100%. Unplug the cable and enjoy!

### ⚠️ Important Notes
- *Browser:* Currently Web Serial API is *NOT supported* on Firefox, Safari and mobile browsers (except for some modded versions on Android).
- *Driver:* If the computer does not recognize the COM port, you need to install the corresponding driver (usually CP210x or CH340).
- *Boot Mode:* If you cannot connect, hold down the *BOOT* button on the board when clicking Connect.
